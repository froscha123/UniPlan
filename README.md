# UniPlan

Учебный проект по дисциплине «Управление программными проектами».

**UniPlan** — информационная система для планирования учебной нагрузки и контроля дедлайнов.

## WBS для лабораторной работы №5

Структура проекта разбита на 5 крупных фаз и 20 конкретных задач:

1. **Анализ и планирование** — [UP-001](https://github.com/froscha123/UniPlan/issues/1)
2. **Проектирование продукта** — [UP-006](https://github.com/froscha123/UniPlan/issues/6)
3. **Разработка MVP** — [UP-011](https://github.com/froscha123/UniPlan/issues/11)
4. **IoT-интеграция и синхронизация** — [UP-017](https://github.com/froscha123/UniPlan/issues/17)
5. **Тестирование и выпуск** — [UP-021](https://github.com/froscha123/UniPlan/issues/21)

Всего создано **25 Issues**: 5 крупных фаз и 20 задач.

## Дорожная карта

| Этап | Срок | Результат |
|---|---|---|
| Анализ и планирование | 1–2 неделя | Уточнены требования, сценарии и состав MVP |
| Проектирование | 3–4 неделя | Архитектура, UX-прототип, API, локализация |
| Разработка MVP | 5–8 неделя | Расписание, задачи, дедлайны, нагрузка, напоминания |
| IoT и синхронизация | 9–10 неделя | Smart-campus прототип и проверка безопасности |
| Тестирование и выпуск | 11–12 неделя | QA, пилот, документация и обратная связь |
